Acerca de NEXUS

NEXUS es una plataforma moderna de conversación y roleplay con inteligencia artificial. Inspirada en estructuras de chat con IA modernas pero con identidad, diseño y código propios.

Características clave:

  • ✓ Sistema de memoria infinita y escalable
  • ✓ Recuperación inteligente de contexto con embeddings
  • ✓ Personajes sin límites (real, ficticio, mixto)
  • ✓ Conversaciones multipersona
  • ✓ Interfaz 100% responsive y moderna
  • ✓ 0 censura - Control total del usuario
  • ✓ Descargable como PWA (Progressive Web App)
  • ✓ Funciona sin conexión (offline-first)
  • ✓ Sistema de Lorebook para inyección de contexto
  • ✓ Exportación e importación de personajes
